NUESTRA CAJITA V2
Abre index.html con VS Code + Live Server.

La sección “Ábreme cuando...” tiene 5 mensajes por carta.
Cada apertura elige aleatoriamente uno y evita repetir inmediatamente
el mensaje anterior. Dentro de cada carta, “Dime otra cosita” genera otro.

Edita principalmente js/data.js para cambiar recuerdos, mensajes, canciones
y planes futuros. No requiere backend ni dependencias.
